# 童阅智伴 · HarmonyOS 家长端

面向 HarmonyOS 的 ArkTS / ArkUI 家长端交互原型，优先呈现 Hi3516 + RFID 阅读器方案。应用包含首页、绘本馆、阅读成长、AI 共读和设备中心五个面板，使用原创绘本插画、圆体中文字体与角色动作，适配手机竖屏。

![五个主面板预览](docs/app-overview.jpg)

## 运行

1. 使用 DevEco Studio 打开本仓库目录。
2. 安装 HarmonyOS SDK API 26（兼容版本与目标版本均为 26.0.0）。
3. 选择 `entry` 模块和 `default` 产品后，在 IDE 中构建并运行。

也可在项目目录使用 DevEco Studio 自带的 Hvigor 工具构建：

```text
hvigorw --mode module -p product=default -p module=entry@default assembleHap
```

项目未包含签名密钥；本地可构建 unsigned HAP，发布或安装到受限设备前需在 DevEco Studio 配置签名。

## 交互范围

- 首页展示当前阅读器的今日进度、连续共读天数和最近阅读记录，也保留应用内共读入口。点击角色可重播挥手，支持减少动态效果。
- 绘本馆提供搜索、分类与年龄筛选、绘本卡片和主题入口。
- 阅读成长按当前阅读器的已同步记录计算本周和上周的共读次数、绘本数、时长和趋势，能力雷达和勋章提供样式预览。
- AI 共读展示预设示例问答、推荐问题和对话记录；输入内容使用本地演示回复。
- 设备中心可连接 RFID 阅读器、扫描和绑定绘本标签，并同步阅读记录和已播报答案的原文证据。绘本包页面支持选择本地 StoryPack 导入阅读器。专注模式、音量和阅读时长设置仍是演示控件。

应用内语音输入与 AI 问答使用演示数据，板端离线语音问答由 StoryPack 驱动。阅读器入口使用 `/v1/` 接口，已同步的阅读记录会在应用重启后保留。应用不上传音频。

真实阅读器的实施顺序、接口草案和真机验收标准见 [Hi3516 + RFID 首轮联调](docs/RFID_MVP.md)。

按原方案附录逐项列出的实现状态与研发缺口见 [方案 B 对照](docs/PLAN_B_STATUS.md)。板端候选默认运行句段级 MFCC/DTW；[电脑 CTC 数字样机](docs/CTC_PC.md) 可输出词位时间并写入模拟会话轨迹。PC 模拟器另有显式开启的原文摘录式自由问句实验，在当前段及同一故事的前后相邻段进行保守检索；它不替代板端当前的审核 FAQ。家长端可查看定位点并复核；点击同步后可将复核状态和备注同步到阅读器，供其他已配对客户端读取。两个独立家长端服务客户端的电脑端到端同步已通过，成长页的位置复核按周统计也已在 HarmonyOS 模拟器验证。双鸿蒙设备 UI 联合操作、语义问答、容错增量对齐、板端 CTC 接入和真实设备验收仍待完成。

绘本导入与导入后刷卡、问答、摘要恢复的回归检查可运行 `python -B -m unittest discover -s tools -p test_storypack_import.py -v`。基础测试不需要开发板；中文语音用例需要先生成带索引的演示包和 Windows 定位器。手机文件选择与上传仍需在连接的鸿蒙设备上验收。

Linux 或 WSL 可进一步启动实际板端进程，用虚拟 PN532 串口、按键与录放音程序完成整机回归，覆盖 HTTPS、刷卡、定位、问答、同步、重启和 UART 故障恢复。命令及依赖见 [虚拟板整机回归](docs/RFID_MVP.md#电脑上的虚拟板整机回归)。

家长端实际服务代码的配对、同步、统计和缓存故障检查见 [服务逻辑电脑回归](docs/RFID_MVP.md#家长端服务逻辑的电脑回归)，使用 DevEco 自带的 TypeScript 包运行，不需要额外安装依赖。
