# Plan B 硬件采购与连接清单

整理日期：2026-11-25。币种：人民币（CNY）。

方案：**Hi3516DV300 + PN532 RFID + USB 声卡 + 小型腔体扬声器 + 云端大模型 + HarmonyOS 家长 App**。

本文用于采购与首轮接线规划。开发板尚未到手，整套组合未完成实物兼容性、性能或 G0—G5 验收。总开发状态以 [README 总 TODO](../README.md)为准；本文对应 B-HW01，实际型号与接线确认对应 B-HW02。

## 1. 采购结论

- 主板选择易百纳 EB-Hi3516DV300-DC-182，要求 **1GB 内存、核心板和底板齐全**，不购买摄像头或显示屏。
- RFID 使用 DFRobot DFR0231-H，通过 **USB 转 3.3V TTL 串口**连接主板。首轮不使用电平尚未确认的主板原生 UART。
- 录音使用绿联 CM129 USB 声卡及外接电脑麦克风。
- 播音使用 **一只 2030 型 8Ω/2W 腔体扬声器 + PAM8406 功放模块**，便于装入外壳。
- 主板通过网线接现有路由器。App 手机连接同一路由器的 Wi-Fi，云端问答需要路由器可访问互联网。
- 大模型使用云端，优先接 DeepSeek，并保留提供方替换接口。语音转文字（ASR）与文字转语音（TTS）仍需单独选型；只接大模型不等于完成语音问答。
- 通用配件优先京东；主板和 DFR0231-H 暂未核实到准确京东同款，采购入口使用厂家渠道。

## 5. PN532 与 CP2102 接线

1. 将 DFR0231-H 拨到 **UART** 模式。
2. CP2102 接主板 **USB Host**，不是主板调试串口。
3. 确认转换模块 TXD/RXD 的实际逻辑电平为 **3.3V**。板上标有 3.3V 电源脚，不等于信号电平已可切换。
4. 依据模块丝印连接，不凭线色判断引脚。

| CP2102 | DFR0231-H | 说明 |
| --- | --- | --- |
| TXD | C/R（UART RXD） | 发送接接收 |
| RXD | D/T（UART TXD） | 接收接发送 |
| GND | GND | 共地 |
| VCC/3V3/5V | 首轮默认不接 | PN532 电源单独核对，不盲用串口板的 3.3V 稳压输出 |

DFRobot 规格给出的模块供电范围为 3.3—5.5V、通信逻辑为 3.3V。规划使用经确认可提供足够电流的稳压 5V 给 PN532 VCC 供电，电源 GND 与 PN532、CP2102 GND 相连。若使用 CP2102 的 USB 5V 引脚供电，应先核实具体模块的电源路径和可用电流，且不再同时接另一电源。

Linux 镜像需提供 `cp210x` 驱动和可访问的串口设备。设备名可能为 `/dev/ttyUSB0`，实际以枚举结果为准；UART 参数为 115200、8N1。现有程序可通过 `--uart` 指定路径，完整 UID 和重复贴卡行为仍需实测。

参考：[DFRobot 引脚与电平说明](https://wiki.dfrobot.com.cn/_SKU_DFR0231_H_Gravity_UART_I2C_NFC%E8%BF%91%E5%9C%BA%E9%80%9A%E8%AE%AF%E6%A8%A1%E5%9D%97_V1_0)、[微雪 CP2102 模块规格示例](https://www.waveshare.com/product/cp2102-usb-uart-board-type-c.htm)。后者用于说明接口要求，不代表京东候选模块就是微雪型号。

## 6. 采音、功放和小型扬声器

### 6.1 麦克风与声卡

- CM129 插入主板 USB Host；麦克风插入 **独立 MIC 孔**。
- MC01 只是当前采购候选。下单前要求卖家确认：该版本用于电脑独立麦克风插孔，插头接点及偏置电源与 CM129 匹配。仅写“3.5mm”仍不足以确定兼容。
- 首轮不要选手机专用四节 TRRS 麦克风；如使用该类设备，需要另配正确的接点转换器。
- Linux 镜像需提供 ALSA、`snd-usb-audio`、`arecord` 和 `aplay`。厂家所说 Linux 免驱不代表所有精简板卡镜像已经启用内核驱动。
- 采音目标为 16kHz、单声道、PCM16。若声卡只暴露 48kHz 等原生格式，需使用 ALSA 格式转换或软件重采样，再将 16kHz PCM 送入定位器；不能预先假定声卡原生支持 16kHz。

### 6.2 CM129 到功放的输入

绿联耳机口输出模拟音频，PAM8406 模块负责驱动小扬声器。选择 **带输入耦合电路的成品板**，供电、输入和输出按模块原理图/丝印确认，不按芯片裸脚图接成品板。

| 音频线接点 | PAM8406 成品板 | 说明 |
| --- | --- | --- |
| 3.5mm TRS Tip（左声道） | IN-L / L 输入 | 本方案只使用左声道 |
| Sleeve（音频地） | 输入 GND | 音频共地 |
| Ring（右声道） | 不接并绝缘 | 不直接与左声道短接 |

软件将正文与答案的人声输出到左声道，或将单声道复制到左右两路。若模块已有 3.5mm 输入插座，可使用完整 TRS 音频线，扬声器仍仅接其中一个输出声道。

### 6.3 功放到扬声器及供电

| PAM8406 成品板 | 连接对象 |
| --- | --- |
| 电源 +5V/VCC | 稳压 5V 电源正极 |
| 电源 GND | 5V 电源负极；与音频输入地按模块设计共地 |
| L+ / OUT-L+ | 扬声器一根线 |
| L- / OUT-L- | 扬声器另一根线 |
| R+、R- | 悬空，不用 |

- **输出 L- 是差分输出端，不是电源地。不能接 GND，不能把左右声道输出并在一起。**
- 5V 功放电源不接到 CM129 耳机输出。首轮用独立合格 5V 电源；若后续改为从主板供电，需要先核对主板供电余量和连接点。
- 8Ω/2W 是扬声器额定规格，不代表功放实际输出一定为 2W；PAM8406 商品所标“5W”也不能直接作为 8Ω 负载下的输出功率。
- 音量从低档开始，避免削波。扬声器与麦克风分开布置，并使用程序已有的播放/监听门控；不据此宣称已有回声消除。
- 2030 只表示常见的小型规格族。微雪同规格示例为 **20×30×6.8mm**，京东候选的厚度、孔位和 PH1.25 接头以卖家图纸为准。PH1.25 尾线通常还需要转到功放端子或焊盘。

参考：[PAM8406 原厂资料](https://www.diodes.com/datasheet/download/PAM8406.pdf)、[小型扬声器尺寸参考](https://www.waveshare.com/product/8ohm-2w-speaker-b.htm)。

GPIO 引脚和上拉电压等主板版本确定后再画引脚图。无源按钮需配正确的输入上拉/消抖，并通过 `gpio-keys` 等方式成为 Linux `evdev` 按键设备，或增加相应输入适配；现有程序不能直接监听任意 GPIO 引脚。板载按键若满足用途，可以减少外接按钮。

### 7.2 microSD

DC-182 候选板资料列出 32MB NOR Flash，不能按 Taurus 的 8GB eMMC 配置理解。需确认 TF 驱动、挂载方式及 Python/库/StoryPack 的部署空间。存储卡可用于扩展文件系统和数据，但不能未经确认就宣称该板支持直接从 TF 启动。

### 7.3 网络与 App

主板网线接路由器 LAN 口；手机接同一路由器 Wi-Fi。关闭阻止手机访问板卡的访客隔离后，按真实地址配置 HTTPS/证书和配对信息。`127.0.0.1` 指当前设备本机，真机局域网联调应填写板卡地址。

现有 App 部分阅读操作使用 PC `/sim` 接口；迁移为正式板端控制接口和真机操作验收仍是后续开发工作，硬件采购不表示这些操作已在实物接通。

## 9. 下单顺序和卖家确认文本

1. **先确认主板**：准确板型、内存、完整底板、配套电源、镜像/SDK/源码、TF 存储方案和 USB 驱动。
2. **再确认 USB RFID 和音频**：CP2102 电平、DFR0231-H 原装型号、CM129、MIC 插头、PAM8406 模块和扬声器接头。
3. **购买通用配件**：按确定接口购买数据线、电源、转接线和按钮；卖家附送的配件从 BOM 扣除。
4. **最后做外壳**：确认麦克风收音、音量、NFC 读距、天线净空、按钮布局和散热后固定结构。

发给主板卖家：

> 需要 EB-Hi3516DV300-DC-182，1GB 内存，核心板和底板齐全，配合适电源，不需要摄像头。用于 Linux 音频/RFID 项目，需要完整 SDK、对应板型可修改镜像/内核与资料，至少两个可用 USB Host，支持 CP2102（cp210x）、USB Audio/ALSA、TF 读写、以太网和 GPIO 按键。需要部署 Python 3.11+、OpenSSL 和 ARMv7 本地程序，可接受自行编译但需要工具链/根文件系统资料。请确认板卡硬件版本、存储配置、准确电源参数、现成驱动情况及整套含税/运费报价；若只有 MPP 音频接口或旧版 OpenHarmony 镜像，请明确说明。

当前优先评估现有 Linux 用户态候选；原方案 B-T04 的 OpenHarmony 小型系统 HAL 适配仍保留未完成，不能因 Linux 能运行而自动勾选。

发给音频配件卖家：

> 麦克风需要接绿联 CM129 的独立麦克风孔，请确认该 MC01 3.5mm 版本的插头接点和供电兼容。扬声器选 2030、8Ω/2W、带线款，请给尺寸和插头图。功放需要 PAM8406 成品板，5V 供电、支持8Ω、带输入耦合电路，优先带音量电位器和端子，请提供供电/音频输入/左右差分输出的接线图；不要只发芯片或不同供电电压的替代模块。
