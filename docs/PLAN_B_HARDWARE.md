## 1. 采购结论

- 主板选择易百纳 EB-Hi3516DV300-DC-182，要求 **1GB 内存、核心板和底板齐全**，基础套餐无需摄像头；表情显示采用第 11 节的独立可选套件。
- RFID 使用 DFRobot DFR0231-H，通过 **USB 转 3.3V TTL 串口**连接主板。首轮不使用电平尚未确认的主板原生 UART。
- 音频选 **微雪 USB TO AUDIO，SKU 18833**：集成板载双麦克风、USB 声卡和扬声器功放，替换桌面麦克风、CM129 和 PAM8406 三件组合。

- 主板通过网线接现有路由器。App 手机连接同一路由器的 Wi-Fi，云端问答需要路由器可访问互联网。
- 大模型使用云端，优先接 DeepSeek，并保留提供方替换接口。语音转文字（ASR）与文字转语音（TTS）仍需单独选型；只接大模型不等于完成语音问答。
- 采购顺序为 **厂家官网或可核实的官方旗舰店 → 授权渠道 → 通用配件店**。微雪音频模块已检索到京东“Waveshare官方旗舰店”结果；搜索页会变化，下单时仍要核对店铺主体、SKU 和所选套餐。其他链接不自动视为官方店。
- 主板和 DFR0231-H 保留厂家渠道。外壳采用后续 3D 打印；先完成桌面上板、测量完整接线后的占用空间，再确定机器人尺寸。**表情面板为可选项**，首轮阅读硬件预算不包含屏幕。

## 5. PN532 与 CP2102 接线

1. 将 DFR0231-H 拨到 **UART** 模式。
2. CP2102 接主板 **USB Host**，不是主板调试串口。
3. 确认转换模块 TXD/RXD 的实际逻辑电平为 **3.3V**。板上标有 3.3V 电源脚，不等于信号电平已可切换。
4. 依据模块丝印连接，不凭线色判断引脚。

| CP2102 | DFR0231-H | 说明 |
| --- | --- | --- |
| TXD | C/R（UART RXD） | 发送接接收 |
| RXD | D/T（UART TXD） | 接收接发送 |
| GND | GND | 共地 |
| VCC/3V3/5V | 首轮默认不接 | PN532 电源单独核对，不盲用串口板的 3.3V 稳压输出 |

DFRobot 规格给出的模块供电范围为 3.3—5.5V、通信逻辑为 3.3V。规划使用经确认可提供足够电流的稳压 5V 给 PN532 VCC 供电，电源 GND 与 PN532、CP2102 GND 相连。若使用 CP2102 的 USB 5V 引脚供电，应先核实具体模块的电源路径和可用电流，且不再同时接另一电源。

Linux 镜像需提供 `cp210x` 驱动和可访问的串口设备。设备名可能为 `/dev/ttyUSB0`，实际以枚举结果为准；UART 参数为 115200、8N1。现有程序可通过 `--uart` 指定路径，完整 UID 和重复贴卡行为仍需实测。

参考：[DFRobot 引脚与电平说明](https://wiki.dfrobot.com.cn/_SKU_DFR0231_H_Gravity_UART_I2C_NFC%E8%BF%91%E5%9C%BA%E9%80%9A%E8%AE%AF%E6%A8%A1%E5%9D%97_V1_0)、[本次选用的微雪 CP2102 模块规格](https://www.waveshare.com/product/cp2102-usb-uart-board-type-c.htm)。其 3.3V/5V 跳帽选择的是对外供电电压，不能据此当作逻辑电平切换。

## 6. 内置音频模块与小型扬声器

### 6.1 USB TO AUDIO：合并麦克风、声卡和功放

- USB TO AUDIO 通过短 USB-A 延长线接主板 USB Host，把音频模块固定在面向使用者的收音位置；不用将它直插在主板边缘并限制布局。
- 板载双麦克风已经配有偏置和采集电路。**不再单买桌面麦克风、裸咪头、MAX9814 或 PAM8406**。厂家明确说明该型号不支持外接麦克风，不能假设有插座可把咪头延长到别处。
- 板载双麦克风不等于麦克风阵列算法、波束成形或 AEC 已实现。两个收音位置均应有声学通路，不能把整个模块密封进实心打印件。
- Linux 镜像需提供 ALSA、`snd-usb-audio`、`arecord` 和 `aplay`。厂家所说 Linux 免驱不代表所有精简板卡镜像已经启用内核驱动。
- 厂家列出 16kHz 等多种采样率，但板端仍要检查实际 USB 描述符与 ALSA 参数。目标为 16kHz、单声道、PCM16；若采集设备输出双声道，需明确选择一路或验证下混方式，再送入定位器。该配置和 Hi3516 上的实际稳定性尚未验收。
- 模块与扬声器均从低音量试起；主板电源需覆盖主板、USB 音频和 CP2102/PN532 的总负载。若 USB 供电不足，先解决电源和线材，再决定是否加供电式 Hub，不能凭“USB 免驱”认定可稳定供电。

参考：[微雪官方产品](https://www.waveshare.net/shop/USB-TO-AUDIO.htm)、[官方 Wiki 的板载麦克风、供电、ALSA 与采样率说明](https://www.waveshare.net/wiki/USB_TO_AUDIO)。

### 6.2 扬声器接口：需要匹配线材

USB TO AUDIO 的扬声器接口为 **PH2.0 4P 差分功放输出**，所选 Speaker (B) 为 **PH1.25 2P**。两者不是同一插头，采购时要求客服配转接线，并按实际模块丝印/资料核实针序。

| USB TO AUDIO 输出标号 | 连接对象 | 说明 |
| --- | --- | --- |
| VOLP | Speaker (B) 的正端 | 左声道正输出，转接到 PH1.25 对应端 |
| VOLN | Speaker (B) 的负端 | 左声道负输出，不是 GND |
| VORP / VORN | 不接并绝缘 | 不使用右声道，不与左声道并联 |

上表表示信号对应关系，不是插座从左到右的针序。软件将人声送到左声道或复制到双声道；仅用一个声道驱动单只扬声器。功放输出不能再接 PAM8406 输入，也不能将负输出接地。

厂家标称单声道 2.6W 的条件为 4Ω BTL，不可照搬到 8Ω 扬声器。Speaker (B) 的额定功率为 2W，首轮调低硬件/软件音量后测试削波、音量与收音串扰；两件官方产品并不自动表示这组转接和音量已由厂家配套验证。若客服不能确认，先完成台架验证，再固定外壳。

DC-182 候选板资料列出 32MB NOR Flash，不能按 Taurus 的 8GB eMMC 配置理解。需确认 TF 驱动、挂载方式及 Python/库/StoryPack 的部署空间。存储卡可用于扩展文件系统和数据，但不能未经确认就宣称该板支持直接从 TF 启动。

### 7.3 网络与 App

主板网线接路由器 LAN 口；手机接同一路由器 Wi-Fi。关闭阻止手机访问板卡的访客隔离后，按真实地址配置 HTTPS/证书和配对信息。`127.0.0.1` 指当前设备本机，真机局域网联调应填写板卡地址。

现有 App 部分阅读操作使用 PC `/sim` 接口；迁移为正式板端控制接口和真机操作验收仍是后续开发工作，硬件采购不表示这些操作已在实物接通。

```text
        +-- OPT-F03 --> 第二只 CP2102（OPT-F02）

                           RXD <------ 屏幕 UART TXD（GPIO43）
                           GND ------- 屏幕 UART GND
                           VCCIO      不接屏幕 3V3/VBus

独立稳压 5V USB-A 电源（OPT-F05）-- OPT-F04 --> 屏幕 USB-C

烧录时：屏幕 USB-C 改接现有电脑 USB 数据口，断开原独立电源。
```

UART 端 `3V3` 为对外供电脚，本方案悬空；不将 5V 接到该脚，也不将屏幕通过两路电源同时供电。以上按原厂 UART 标号连接，不是插头的左右针序图；CP2102 TX/RX 逻辑为 3.3V。首轮不用电平待确认的 Hi3516 原生 UART，保留 USB 串口方案。

两只 CP2102 分别服务 RFID 和表情；设备节点需按实际枚举、唯一标识或固定 USB 端口规则区分，不能固定假设 `/dev/ttyUSB0` 与 `/dev/ttyUSB1` 的顺序。规划 115200、8N1；ESP32 固件需将协议和调试日志分开，并处理默认 UART0 日志对 GPIO43/44 通信的影响。这些是后续 B-FACE02 的适配工作，出厂示例不会自动显示 Hi3516 阅读状态。

### 11.4 尺寸、安装与后续软件

官方机械图给出的外形参考为 **73.06×50.54mm**，显示区约 **57.60×43.20mm**；板孔参考间距 **60×41mm**、孔径 **φ2.5mm**。这些是二维参考，**不是包含后背元件、USB 插头、UART 尾线弯曲和支架的装配厚度**，V2 到货后按实际版本和原厂图纸复核。参考：[官方尺寸图](https://www.waveshare.net/photo/development-board/ESP32-S3-Touch-LCD-2.8/ESP32-S3-Touch-LCD-2.8-details-size.jpg)。

先用支架试片确认孔位和屏幕可视区，保留 USB-C 烧录、BOOT/RESET 和拆装通道；前框不挤压面板排线，安装件避开天线和主板散热区域。依据完整接线后的尺寸确定头部开窗，继续遵循“先上板、后定整壳”的顺序。

可选 B-FACE02 计划让 Hi3516 发送状态码，ESP32 在本地绘制待机/眨眼、识别绘本、朗读、监听、思考、回答、断网/错误表情。需要补协议、去重/确认、心跳超时、重连、串口权限和开机启动；表情线程与阅读流程隔离，屏幕失联时阅读和记录照常工作。先在电脑通过串口验证，再在真实 Hi3516 验证三路 USB 共存、音频连续性、功耗、重启恢复和装壳温升；尚未开发或验收。
